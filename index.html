Agentic Migration Factory

A team of AI agents that migrates legacy T-SQL and SAS jobs to PySpark on a bronze / silver / gold lakehouse. The agents map column-level lineage, order jobs into waves, write the PySpark, run it, and reconcile every output against the legacy system before a human signs off. When a job doesn't match, the diff goes back to the model to fix, up to three attempts.

My part: the migrate-and-repair loop with model escalation, the review dashboard, and a standalone two-system validator that compares legacy and cloud outputs as files, live queries or both.
